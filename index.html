首页 · 宠物状态总览

从宠物出发，看今天的整体状态。

页面构成

品牌 Logo、消息与添加设备入口；宠物切换条（Lucky 金毛 / Milo 黑色拉布拉多 / Coco 腊肠犬，头像为与状态动效匹配的正面卡通图）；状态卡（标题、状态胶囊标签、Activity / Sleep 小卡、右侧宠物状态图：Lucky / Milo / Coco 分别使用本次生成的透明 GIF 动效，对应睡觉 / 走路 / 玩球，带呼吸与位移，随当前宠物切换，另有 AI 洞察条）；Quick Access 四个彩色圆形入口（My Pet·狗、Voice Translation·麦克风、Device·设备、Electronic Fence·围栏，图标 SVG 已内联，离线可用），标题右侧 See All 可自定义入口；Focus on Lucky 提示卡；关联设备列表。

可交互内容

  • 点右上角「+」或设备区底部「+ Add Device」，打开同一个添加设备弹框（Smart Dog Harness / Smart Dog House，型号均为 Model 001）。
  • 选择 Smart Dog Harness 并确认后进入参数弹框：参数以 MQTT_Protocol.pdf 为准（MQTT 3.1.1、Broker、Client ID、Topic、上报字段、事件与可配置上报间隔）；先选 Linked pet 关联宠物（下拉列出系统内已添加的宠物，默认当前选中），再填 IMEI 与上报间隔；添加完成后设备归属该宠物。
  • 点 Smart Dog House 会提示「Device in production」，暂不提供后续弹框。
  • 可切换 Lucky、Milo、Coco 或 All Pets；点状态卡进入健康详情，点洞察条进入 AI 管家。
  • Quick Access 标题右侧 See All 打开设置菜单：My Pet / Voice Translation / Device / Electronic Fence / Genetic Test 五项可开关，最多同屏 4 个；按住左侧手柄可拖拉调整顺序，顺序与显示状态随刷新保留。
  • 设备区按当前宠物过滤：Lucky 2 台（Harness + Dog House）、Milo 1 台（Harness）、Coco 无设备（显示 No devices yet）、All Pets 合计 3 台。
  • 新用户首次可点设备区「Add Device」进入首次绑定流程：只支持扫码绑定（智能设备 / 基因检测盒），没有「选择已有设备」「稍后绑定」选项；必须先绑定产品、创建宠物并完成关联才能进入首页。

演示范围

新设备只写入当前浏览器的演示数据；参数为协议文档摘要，不建立真实 Broker 连接。

【手机框迁出】设备在线/离线状态为示例，可在设备详情中切换；首页状态卡与数值不代表真实检测结果。

页面构成

按当前宠物展示活动、生命体征、睡眠与消化四类健康示例数据，可进入指标详情与专业报告。

可交互内容

  • 选择宠物，切换 Today、7 Days 或指定日期，数据与趋势随之变化。
  • 点指标卡查看详情；点报告入口查看当前宠物的专业报告。
  • 点健康检测查看检测进度，结果回到当前宠物；可通过病历与兽医入口进入随访流程。

演示范围

图表由网页组件绘制，跟随切换自适应；数据为演示数据，不代表真实检测或医疗判断。

【手机框迁出】健康指标与趋势均为示例数据，不代表真实检测或医疗判断。

AI 管家 · 宠物专属对话

每个问题都围绕当前宠物。

页面构成

以对话形式演示健康解读、状态查询与养宠建议；聊天再长，输入条始终固定在底部菜单之上。

可交互内容

  • 在顶部点宠物名切换（每只宠物各自保留对话）；消息滚动时该行固定不动。点 Clear 清空这只宠物的本地对话。
  • 输入问题发送，或点推荐问题，查看基于示例数据生成的预置回复。
  • 点「+」可为当前宠物添加四类附件：上传文件（支持 PDF、DOC、DOCX、TXT 等文档）、上传图片（从相册选择）、拍照（调用手机相机）、已就绪的 DNA 报告；报告回复会概括血统构成、遗传风险与特征。发送前可移除附件。
  • 点健康数据、专业报告或在线兽医，继续体验关联流程。

演示范围

回复来自本地规则与示例模板，未接入真实 AI 模型，不做图像识别、不解析文件内容；照片与文件只保留在当前浏览器会话。不发送任何网络请求。

【手机框迁出】AI 管家回复来自本地预置规则与模板，未接入真实模型，不发送网络请求。

发现 · 宠物社区

分享日常，认识更多毛孩子。

页面构成

按评审截图改为搜索栏 + 话题筛选 + 双列瀑布流卡片；卡片统一为图片轮播、标题、两行摘要与发布者信息，保留社区浏览、互动、发布与作者主页。

可交互内容

  • 顶部搜索栏按标题、副标题、作者与话题实时筛选卡片。
  • 分类胶囊可左右拖动（桌面端鼠标按住拖、手机端滑动）查看更多分类：For You / Following / Health / Training / Nutrition / Care / Grooming / Play / Adoption；最右侧圆形按钮打开 Stories 作者列表。
  • 卡片顶部为多图时每 3 秒自动轮播并带指示点；图片下方依次为标题、两行摘要、发布者头像与昵称、点赞数。
  • 点卡片进入帖子详情，支持点赞、收藏、评论、多图切换与话题聚合。
  • 右上角「+」发布图文，新内容进入信息流与个人主页；底部悬浮胶囊导航切换五大模块。

演示范围

点赞、评论、关注与图文内容保存在当前浏览器；上传图片仅保留在本次打开的会话中，不会发布到真实社区。

新用户设备绑定 · 首次开箱

扫描产品绑定码 → 绑定账号 → 建立宠物档案 → 关联产品与宠物 → 进入首页。

页面构成

新用户首次开箱流程，步骤①提供两种取号方式：扫码，或手动输入产品标签上的 SN 码；步骤②宠物档案区分 Dog / Cat 并标注必填项；没有「选择已有设备」「稍后绑定」选项；必须完成产品绑定与宠物关联才能进入首页。

可交互内容

  • 第 1 步：点 Scan QR code 模拟扫码，或在输入框填写 SN 码后点 Confirm，两种方式二选一；未确认前下方不显示任何产品信息，确认成功后下方才出现产品图片、产品名称与 SN 号，可点 Change 重新扫码或重新输入。
  • 第 2 步：点 Bind to account，把产品绑定到当前账号，产品出现在 My Devices 中。
  • 第 3 步：填写宠物档案——Type 置于表单最上方，可选 Dog / Cat（默认 Dog），切换后下方尺寸筛选与犬种区随之联动；Pet name、Type、Breed、Age、Sex、Weight、Height 前七项为必填，标签后带红色 * 标识；Emotional history、Owner、Contact、Next vaccination 为选填。选 Cat 时犬种图卡暂不提供，直接手填 Breed。
  • 第 4 步：Photos 改为普通图片上传，不区分前后左右角度，最多 12 张、也可一张不传（0 张即可继续）；点 Finish setup 显示「绑定成功」完成页，并自动 5 秒倒计时回到首页，也可点 Go to Home 立即进入。

与 Add Pet 的区别

Add Pet 面向已有宠物的用户：可以扫描新设备、从已有设备列表中选择，或选择 I’ll link a device later 跳过；新用户设备绑定只能扫码，且必须绑定账号、创建宠物并关联产品，不能跳过。

演示范围

扫码、SN 校验、绑定与照片上传均为本地模拟，不连接真实硬件（SN 码任意填写即视为有效）；照片仅保留在当前会话，重置演示后清空。

【手机框迁出】设备绑定为本地演示数据，不扫描也不连接真实设备。

宠物语言翻译

暖橙 + 品牌蓝双色录音翻译页：2 个方向选项、完整状态链与历史联动。

页面构成

Translation Mode 只有 2 个选项：Dog → Human 与 Cat → Human，每个选项用「宠物图标 → 人形图标」表达方向（宠物暖橙、人形品牌蓝）；选项右侧的圆形切换按钮点击后就地翻转为 Human → Dog / Human → Cat，两个选项各自记住自己的方向。中央大录音按钮带呼吸光晕与极简爪印装饰；录音中显示动态声波；结果以气泡卡展示并支持模拟播放；页面角落有低透明度爪印剪影。

可交互内容

  • 首次进入弹出麦克风权限引导；点主按钮开始录音，点结束依次进入 Analyzing audio... / Generating interpretation...，生成后自动存入历史。
  • 每条历史支持播放（重听）、View Pet Health Report（跳转健康报告）、删除；空态为插画卡 + Start Recording 引导。
  • 点选项即选中该宠物，点切换按钮只翻转该选项的方向（两个图标左右互换、箭头随之改变方向，切换按钮旋转 180° 并转为蓝色底）；录音中切换会提示先结束录音。切换有平滑过渡，录音按钮有按下压缩反馈。
  • 图标：Switch / Dog / Human / Cat 四个图标取自 Font Awesome v5 实体库（repeat / dog / cat / user-alt），SVG path 已内联进 app.js，不依赖 CDN、不额外加载字体；空态插画中的宠物剪影随选中宠物切换。配色：宠物与操作用暖橙主色，「人类」方向图标、播放按钮、View Pet Health Report 等跨模块入口用 Logo 蓝（#2165b0）；页面另有右上冷色 / 左下暖色低透明度晕染，混合但不抢主体。
