Home · Pet status overview

Start from pets, understand today's status.

Page features

Brand Logo, messages and add-device entry; pet switch bar (Lucky golden retriever / Milo black Labrador / Coco dachshund, avatars are cartoon front-facing images matching each state animation); status card (title, status pill, Activity / Sleep mini cards, right-side pet status image: Lucky / Milo / Coco use the transparent GIF animations generated this time, sleeping / walking / playing ball respectively, with breathing and motion; switches with current pet), AI insight bar); Quick Access four colored round entries (My Pet·dog, Voice Translation·microphone, Device·device, Genetic Test·dna, SVG inlined for offline use); Focus on Lucky tip card; linked device list.

What you can do

  • Tap "+" at top-right or "+ Add Device" at device area bottom to open the same add-device dialog (Smart Dog Harness / Smart Dog House, both Model 001).
  • Select Smart Dog Harness and confirm to enter parameter dialog: parameters from MQTT_Protocol.pdf (MQTT 3.1.1, Broker, Client ID, Topic, reporting fields, events and configurable reporting interval); first select Linked pet to associate a pet (dropdown lists pets added in system, default current selected), then fill IMEI and reporting interval; after adding, device belongs to that pet.
  • Tap Smart Dog House will prompt "Device in production", no further dialog provided for now.
  • Switch Lucky, Milo, Coco or All Pets; tap status card to enter health details, tap insight bar to enter AI Butler.
  • Device area filters by current pet: Lucky 2 units (Harness + Dog House), Milo 1 unit (Harness), Coco no devices (shows No devices yet), All Pets totals 3 units.
  • New users first time can tap "Add Device" in device area to enter new-user binding flow: supports scan binding only (smart device / genetic test kit), no "choose existing device" or "bind later" options; must bind product, create pet and associate before entering Home.

Demo scope

New device only writes to current browser demo data; parameters are protocol doc summary, no real Broker connection.

[Moved out of phone frame] Device online/offline status is sample, can be switched in device details; home status card and values do not represent real detection.

New-user device binding · First-time setup

Scan product binding code → Bind account → Build pet profile → Associate product and pet → Enter Home.

Page features

New user first-time unboxing flow, supports scan binding only (smart device / genetic test kit), no "choose existing device" or "bind later" options; must complete product binding and pet association before entering Home.

What you can do

  • Step 1: Tap Scan QR code, simulate scanning product binding code (Smart Dog Harness / Smart Dog House / genetic test kit), screen shows product serial number.
  • Step 2: Tap Bind to account, bind product to current account, product appears in My Devices.
  • Step 3: Create pet profile (name, breed, sex, weight), and upload 8 angle pet photos for digital life generation; must have all 8 photos to proceed to next step.
  • Step 4: Associate bound product with new pet, tap Link & finish to complete first-time setup, system enters Home.

Difference from Add Pet

Add Pet is for existing pet users: can scan new device, or choose from existing device list, or choose I\'ll link a device later to skip; new-user device binding can only scan, must bind account, create pet and associate product, cannot skip.

Demo scope

Scan, binding and photo upload are all local simulation, no real hardware connection; photos kept only in current session, cleared after demo reset.

[Moved out of phone frame] Device binding is local demo data, no scan or connect to real device.

Pet language translation

Warm orange + brand blue two-color recording translation page: 2 direction options, complete status chain and history linkage.

Page features

Translation Mode has only 2 options: Dog → Human and Cat → Human, each option uses "Pet icon → Human icon" to indicate direction (pet warm orange, human brand blue); the circular switch button on the right of each option taps to flip in place to Human → Dog / Human → Cat, each option remembers its own direction. Central large recording button with breathing glow and minimalist paw decoration; during recording shows dynamic audio waveform; result shown in bubble card with simulated playback support; page corner has low-opacity paw silhouette.

What you can do

  • First entry pops up microphone permission guide; tap main button to start recording, tap end to enter Analyzing audio... / Generating interpretation... in sequence, after translation generated auto-saved to history.
  • Each history supports Play (replay), View Pet Health Report (jump to health report), Delete; empty state is illustration card + Start Recording guide.
  • Tap option to select that pet, tap switch button to flip only that option\'s direction (two icons swap left-right, arrow changes direction accordingly, switch button rotates 180° and turns blue background); switching during recording prompts to end recording first. Switch has smooth transition, recording button press compression feedback.
  • Icons: Switch / Dog / Human / Cat four icons from Font Awesome v5 solid library (repeat / dog / cat / user-alt), SVG paths inlined into app.js, no CDN, no external font dependency; empty state illustration pet silhouette switches with selected pet. Color scheme: warm orange main color for pet and operation, Logo blue (#2165b0) for "human" side icons, play button, View Pet Health Report and other cross-module entries; page also has top-right cool color / bottom-left warm color low-opacity wash, both mixed without stealing the main subject.
