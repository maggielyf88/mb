首页 · 宠物状态总览

从宠物出发，了解今天的状态。

页面功能

品牌 Logo、消息与添加设备入口；宠物切换条（Lucky 金毛贵宾 / Milo 黑色拉布拉多 / Coco 腊肠犬，头像均为与各自状态动图同款形象的卡通正面头像）；状态卡（标题、状态胶囊、Activity / Sleep 小卡、右侧宠物状态图：Lucky / Milo / Coco 均使用本次生成的透明 GIF 动图，分别为睡觉 / 散步 / 玩球，自带呼吸与动作；随当前宠物切换）、AI 洞察条）；Quick Access 四个彩色圆形入口（My Pet·dog、Voice Translation·microphone、Device·device、Genetic Test·dna，SVG 内联以保证离线可用）；Focus on Lucky 提示卡；关联设备列表。

可以怎样操作

  • 点击右上角「+」或设备区底部的「+ Add Device」，弹出同一个添加设备弹框（Smart Dog Harness / Smart Dog House，均 Model 001）。
  • 选择 Smart Dog Harness 并确认，进入参数弹框：参数取自 MQTT_Protocol.pdf（MQTT 3.1.1、Broker、Client ID、Topic、上报字段、事件与可配置上报间隔）；先选 Linked pet 关联宠物（下拉列出系统内已添加的宠物，默认当前选中宠物），再填写 IMEI 与上报间隔，加入后设备即归属该宠物。
  • 点击 Smart Dog House 会提示「该设备生产中」，暂不提供后续弹框。
  • 切换 Lucky、Milo、Coco 或 All Pets；点击状态卡进入健康详情，点击洞察条进入 AI 管家。
  • 设备区随当前宠物过滤：Lucky 2 台（Harness + Dog House）、Milo 1 台（Harness）、Coco 无设备（显示 No devices yet），All Pets 汇总 3 台。
  • 首次使用的新用户可点设备区「Add Device」进入新用户绑定流程：仅支持扫码绑定（智能设备 / 基因检测试剂盒），不提供“选择已有设备”或“稍后绑定”，须绑定产品、创建宠物并关联后才能进入 Home。

演示范围

新增设备仅写入当前浏览器演示数据；参数为协议文档摘要，不连接真实 Broker。

【手机框迁出】设备在线 / 离线状态为示例，可在设备详情切换；首页状态卡与数值不代表真实检测。

健康 · 数据与趋势

看见状态，也看懂变化。

页面功能

按当前宠物展示活动、生命体征、睡眠和消化等健康示例数据，支持进入指标详情和专业报告。

可以怎样操作

  • 选择宠物，切换 Today、7 Days 或指定日期，数据和趋势同步变化。
  • 点击指标卡查看详情；点击报告入口查看当前宠物的专业报告。
  • 点击健康检测观看检测进度，结果回到当前宠物；通过记录和兽医入口进入后续流程。

演示范围

图表由网页组件绘制，可响应切换；数据为演示数据，不代表真实检测或医学判断。

【手机框迁出】健康指标与趋势为示例数据，不代表真实检测或医学判断。

AI 管家 · 宠物专属对话

让每一次提问，都围绕当前宠物。

页面功能

  • 点击健康数据、专业报告或在线兽医，继续体验关联流程。

演示范围

【手机框迁出】AI 管家回复来自本地预设规则与模板，没有连接真实 AI 模型，也不会发送网络请求。

发现 · 宠物社区

分享日常，遇见更多毛孩子。

页面功能

按评审截图改为搜索栏 + 话题筛选 + 双列瀑布流卡片；卡片统一为图片轮播、标题、两行简述与发布人信息，保留社区浏览、互动、发布和作者主页。

可以怎样操作

  • 顶部搜索栏按标题、副文本、作者与话题实时筛选卡片。
  • 切换 For You / Following / Health / Training / Nutrition / Care；最右侧圆形按钮打开 Stories 作者列表。
  • 卡片顶部图片有多张时每 3 秒自动轮播并显示指示点；图片下方依次是标题、两行简述、发布人头像与名称及点赞次数。
  • 点击卡片进入帖子详情，支持点赞、收藏、评论、多图切换及话题聚合。
  • 右上角加号发布图文，新内容进入信息流与个人主页；底部悬浮胶囊导航切换五个主模块。

演示范围

点赞、评论、关注和图文文字保存在当前浏览器；上传图片仅在当前打开会话保留，不会发布到真实社区。

宠物建档 · 新增与编辑

按评审截图重建的 Add Pet 表单。

页面功能

改为 3 个标签卡的分步流程：① Connect device（扫码绑定 / 选择已有设备 / 暂不绑定）；② Pet profile（犬种照片+名称选择、两列 10 字段、新增下次疫苗接种时间）；③ Photos（8 角度照片）→ 完成提示 → 进入 Home。顶部标签卡可点击回跳。

可以怎样操作

  • 步骤①：选 Scan 后点 Scan QR code 自动填入示例 IMEI；标题与说明已改为“Scan a device or genetic test box”，可扫描设备或基因检测盒子；选 Use an existing device 从下拉挑设备，若设备已绑定其他宠物会弹窗询问是否变更主人；也可选 I'll link a device later 跳过。
  • 步骤②：点“小型 / 中型 / 大型”快速筛选可切换相关尺寸的犬种卡片；点犬种照片卡自动填入 Breed；字段校验宠物名与体重必填。
  • 步骤③：点击虚线照片框选本地图片预览；新建时必须凑齐 8 张才能保存，编辑已有宠物时不重复要求。
  • Save & Finish 后显示 All set! 完成页，点 Go to Home 进入首页；设备绑定/主人变更在保存时生效。

演示范围

照片仅保存在当前浏览器会话，使用 blob URL 预览，不上传服务器；犬种照片使用现有示例狗图，仅用于演示选择交互。App 内文案按项目约定使用英文，参考截图为中文界面。

Genetic Test 基因检测

页面功能

按当前宠物展示基因检测记录，状态分为 Sample submitted（送检中）、Testing in progress（检测中，只读）、Report ready（报告可查看）。

可以怎样操作

  • Add Genetic Test：扫码 → 宠物基本信息（可编辑）→ 确认生成送检中记录。

演示范围

两个 Simulate 按钮用于演示状态流转，非真实送检；数据仅本地保存。报告为示例，不构成医疗诊断。

宠物语言翻译

暖橙 + 品牌蓝双色的录音翻译页：2 个方向选项、完整状态链路与历史联动。

页面功能

Translation Mode 下只有 2 个选项：Dog → Human 与 Cat → Human，每个选项用「宠物图标 → 人图标」表示方向（宠物暖橙、人品牌蓝），选项右侧的圆形切换按钮点一下即原地翻转成 Human → Dog / Human → Cat，两个选项各自记住自己的方向。中央大号录音按钮带呼吸光晕与极简爪印装饰，录音中显示动态音频波形；结果以气泡卡片展示并支持模拟播放；页面角落有低透明度爪印剪影。

可以怎样操作

  • 首次进入弹出麦克风权限引导；点主按钮开始录音，再点结束依次进入 Analyzing audio... / Generating interpretation...，生成译文后自动存入历史。
  • 每条历史支持 Play（重放）、View Pet Health Report（跳转健康报告）、删除；空态为插画卡片 + Start Recording 引导。
  • 点选项即选中该宠物，点切换按钮只翻转该选项的方向（两个图标左右互换、箭头随之换向，切换按钮转 180° 并变蓝底）；录音进行中切换会被提示先结束录音。切换有平滑过渡，录音按钮按压缩放反馈。
  • 图标：切换 / 狗 / 人类 / 猫 四个图标取自 Font Awesome v5 实体库（repeat / dog / cat / user-alt），SVG 路径已内联进 app.js，不引 CDN、不依赖外部字体；空态插画的宠物剪影会随所选宠物切换。配色：暖橙主色承担宠物与操作，Logo 蓝（#2165b0）承担「人」侧图标、播放键、View Pet Health Report 等跨模块入口，页面另有右上冷色 / 左下暖色的低透明度冲洗，两者混合不抢主体。

从预设食品中加入收藏。

页面功能

提供几种本地预设宠物食品。

可以怎样操作

  • 点击添加后加入我的食品；已添加的食品显示对应状态。

演示范围

不购买商品，也不获取外部商品数据。

添加食品

填写一条自定义食品资料。

页面功能

提供食品名称、品牌及适用宠物类型。

可以怎样操作

  • 填写名称与品牌后保存，随后可在喂养计划中选择。

演示范围

数据仅在本地保存。
