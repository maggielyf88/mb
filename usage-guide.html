MoonBack 使用与编辑指南

一份可以直接转发的离线交互原型：左侧操作 App，右侧阅读功能说明。

1. 怎样打开与转发？

  1. 先把整个 ZIP 压缩包解压到一个普通文件夹。不要只在压缩软件中打开单个 HTML。
  2. 双击文件夹中的 index.html，用 Chrome、Edge、Safari 或 Firefox 等现代桌面浏览器打开。
  3. 无需安装开发环境、启动服务或连接互联网。Windows 与 macOS 都可使用。
  4. 转发时发送整个 ZIP，或将完整文件夹重新压缩。不要只发 index.html，因为图片、样式和脚本也需要一起保留。

2. 怎样体验？

  • 顶部 Tab 切换主要模块；手机底部菜单与顶部 Tab 双向同步。
  • 手机画面内可以单独滚动。点击按钮可进入子页面，右侧说明随页面更新。
  • 右上方“页面快速定位”可直接查看所有页面，适合评审时快速跳转。
  • 默认展示 Lucky、Milo、Coco，以及多台示例设备。可新增宠物、绑定演示设备、切换健康趋势、发送 AI 演示消息、发布图文、点赞评论和修改个人资料。
  • 手机下方提供登录、空数据与登录过期场景；右上角“重置演示”可恢复初始示例。
  • 本地模拟登录可填手机号 13800138000 或邮箱 demo@example.com；密码填写任意至少 6 位的演示字符并勾选演示协议。也可点击“一键体验演示账号”。找回密码的演示验证码是 123456。

3. 怎样修改右侧说明？

  1. 右键 index.html，选择用文本编辑器打开（例如 VS Code、Windows 记事本；macOS 文本编辑请使用纯文本模式）。
  2. 搜索 右侧功能说明编辑区，或直接搜索页面标题，如 首页 · 宠物状态总览。
  3. 每个页面有一个独立的 section。修改其中 h2、h3、p、li 内的文字；也可以增加段落或列表项。
  4. 以 UTF-8 格式保存。确保文件名仍是 index.html，不是 index.html.txt。
  5. 回到浏览器刷新即可看到修改，不需要改 JavaScript，不需要重新构建。左侧演示操作不会覆盖 HTML 中修改的说明。
<!-- ===== 首页 · 宠物状态总览：修改以下文字即可 ===== -->
<section class="doc-page" id="doc-home"
         data-page="home" data-group="home" hidden>
  <h2>首页 · 宠物状态总览</h2>
  <p class="lead">这里可以修改页面副标题。</p>
  <h3>页面功能</h3>
  <p>这里写你自己的功能介绍。</p>
  <h3>可以怎样操作</h3>
  <ul>
    <li>这里写第一项操作说明。</li>
    <li>这里写第二项操作说明。</li>
  </ul>
</section>

请保留 section 的 id、data-page、data-group 和 class，不要修改它们的值，也不要删除 hidden。这些属性用于页面联动。
文字中如需写“<”或“&”，请分别使用 &lt; 和 &amp;。

4. 文件夹结构

MoonBack-Interactive/
├── index.html       ← 双击打开；右侧说明直接在这里修改
├── 使用说明.html     ← 本指南
├── 请先阅读.txt      ← 快速开始
├── style.css        ← 网页与 App 的样式
├── app.js           ← 导航、交互、模拟数据
└── assets/          ← 图片与字体，必须完整保留

5. 数据与模拟范围

  • 普通演示资料和互动会尝试保存在当前浏览器的本地存储中。不同浏览器、不同文件路径可能有各自的数据；修改后的演示状态不会自动写回 HTML，也不会随 ZIP 发给别人。
  • 如果浏览器禁用了本地存储，页面会提示“会话模式”，刷新或关闭后可能恢复初始数据。
  • 上传的社区图片只在当前打开会话保留；重新打开后，已发布图文使用内置替代图。图片不会上传到网络。
  • 账号、AI、兽医、录音翻译、监控画面、地图轨迹、购物、会员和固件升级都属于本地模拟，不连接真实服务，不采集麦克风或定位，不产生费用。
  • 报告下载为当前宠物的 HTML 演示摘要，不是 PDF 或正式医疗报告。
  • 语言偏好只记录所选值，原型保留当前 Demo 中英混合的界面文案。
  • “重置演示”只重置浏览器中的示例数据，不会改变你在 HTML 中编辑过的右侧说明。

6. 常见问题

只看到说明，没有手机界面？

确认压缩包已完整解压，app.js 与 style.css 在入口旁边，并使用允许 JavaScript 的普通浏览器。聊天软件内置预览器、邮件预览器或压缩包预览器可能不执行脚本。

图片没有显示？

请确认整个 assets 文件夹已一起解压，且没有改动文件名或相对位置。

怎样把说明修改版发给别人？

保存 HTML 后，将完整文件夹重新压缩并发送；对方解压后双击 index.html 即可看到你修改后的文字。
